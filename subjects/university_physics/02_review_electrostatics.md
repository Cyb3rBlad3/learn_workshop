# 电磁学部分统领复习（一）：静电场与导体电介质（第五~六章）

> 学习日期: 2026-05-12
> 所属科目: 大学物理
> 难度要求: ⭐⭐⭐掌握

## 概述

静电场是电磁学的起点。核心任务是两个：**求电场分布**和**求电势分布**。掌握两大工具——高斯定理和叠加原理——就能应对大部分题目。

---

## 一、静电场（第五章）

### 1.1 库仑定律与电场强度

**库仑定律**：

```
F = (1/4πε₀) · (q₁q₂/r²) · r̂
```

**电场强度**：

```
E = F/q₀ = (1/4πε₀) · (q/r²) · r̂   （点电荷的电场）
```

**叠加原理**：多个电荷产生的总电场 = 各电荷单独产生的电场的矢量和

```
E = ΣEᵢ （离散分布）
E = ∫dE  （连续分布）
```

### 1.2 高斯定理 ⭐⭐⭐ 核心工具

```
∮ E·dA = Σq内/ε₀
```

**使用条件**：电荷分布具有高对称性（球对称、柱对称、面对称）

**应用三步法**：
1. **分析对称性**，判断 E 的方向和大小的分布规律
2. **选取高斯面**（使 E 在面上为常数或为零）
3. **计算**：左边 = E·S（面积），右边 = q内/ε₀

### 三种经典高斯定理问题

#### (1) 均匀带电球面（半径 R，总电荷 Q）

```
r > R:  E = Q/(4πε₀r²)     （等价于点电荷）
r < R:  E = 0               （球壳内部无电场）
```

#### (2) 无限长均匀带电直线（线电荷密度 λ）

```
E = λ/(2πε₀r)    （方向沿径向向外/内）
```

高斯面：同轴圆柱面（半径 r，长度 l），只有侧面有通量

#### (3) 无限大均匀带电平面（面电荷密度 σ）

```
E = σ/(2ε₀)     （与距离无关！方向垂直平面向外）
```

高斯面：扁平圆柱（"药片"形），两个底面各有通量

### 1.3 电势 ⭐⭐⭐

**定义**：V = Ep/q₀ = -∫(从参考点到该点) E·dl

**点电荷的电势**：

```
V = q/(4πε₀r)     （取无穷远为零电势点）
```

**电势叠加原理**（标量叠加，比电场叠加简单）：

```
V = ΣVᵢ = Σ qᵢ/(4πε₀rᵢ)
```

**电场强度与电势的关系**：

```
E = -dV/dr   （一维）
E = -∇V      （三维梯度）
```

### 常见题型

**题型 1：用高斯定理求 E**
- 球对称/柱对称/面对称的电荷分布
- 关键：正确选择高斯面

**题型 2：用叠加原理（积分法）求 E**
- 非对称连续分布（如有限长带电直线、带电圆环轴线）
- 方法：取微元 dq → 写出 dE → 利用对称性简化 → 积分

**题型 3：求电势**
- 方法 a：已知 E，用 V = -∫E·dl 积分
- 方法 b：直接用电势叠加原理 V = ∫dq/(4πε₀r)

**题型 4：已知 V(r)，求 E(r)**
- 用 E = -dV/dr 求导

### 典型例题

**例题：均匀带电球体（体电荷密度 ρ，半径 R）的电场**

高斯面：同心球面，半径 r

**r > R（球外）**：
```
E · 4πr² = Q/ε₀ = (4/3)πR³ρ/ε₀
E = ρR³/(3ε₀r²)
```

**r < R（球内）**：
```
E · 4πr² = (4/3)πr³ρ/ε₀
E = ρr/(3ε₀)
```

球内 E 与 r 成正比，球外 E 与 r² 成反比。

### 易错点
⚠️ **高斯定理右边是"内部"电荷**：只算高斯面内的电荷，外部电荷虽然影响 E 的分布，但不影响总通量
⚠️ **电势是标量**：叠加时直接加减，不需要分解分量。但要注意正负号（正电荷产生正电势）
⚠️ **E = 0 不代表 V = 0**：导体内部 E = 0，但 V 是常数（不一定为零）
⚠️ **两个无限大平行板之间**：E = σ/ε₀（不是 σ/2ε₀，因为两板的场叠加）

## 二、导体与电介质（第六章）

### 2.1 静电平衡 ⭐⭐⭐

导体达到静电平衡时：
- **导体内部 E = 0**
- **导体是等势体**（表面是等势面）
- **电荷只分布在导体表面**
- 导体表面 E 垂直于表面

### 2.2 电容器 ⭐⭐⭐

**电容定义**：C = Q/U（U 为两极板间电势差）

**平行板电容器**：

```
C = ε₀S/d    （S 为面积，d 为板间距）
```

有电介质时：C = εᵣε₀S/d = εS/d

**串联和并联**：
- 串联：1/C总 = 1/C₁ + 1/C₂ + ...
- 并联：C总 = C₁ + C₂ + ...

### 2.3 静电场的能量 ⭐⭐⭐

**电容器储能**：

```
W = ½QU = ½CU² = Q²/(2C)
```

**电场能量密度**：

```
w = ½ε₀E²   （真空中）
w = ½εE²     （有电介质）
```

### 常见题型

**题型 1：导体静电平衡分析**
- 求导体表面/外部电场、电荷分布
- 方法：利用静电平衡条件 + 高斯定理

**题型 2：电容器计算**
- 求平行板/圆柱/球形电容器的电容
- 步骤：假设带电 ±Q → 求 E → 求 U = ∫E·dl → C = Q/U

**题型 3：电容器储能 + 能量密度**
- 求电容器的静电能
- 求电场能量密度分布

### 典型例题

**例题：平行板电容器充电后断开电源，然后插入介电常数 εᵣ = 2 的电介质，求各物理量变化。**

断开电源 → Q 不变

| 物理量 | 公式 | 变化 |
|--------|------|------|
| Q | 不变 | Q |
| C | εᵣε₀S/d | 变为 2C₀ |
| U = Q/C | Q/(2C₀) | 变为 U₀/2 |
| E = U/d | U₀/(2d) | 变为 E₀/2 |
| W = Q²/(2C) | Q²/(2·2C₀) | 变为 W₀/2 |

### 易错点
⚠️ **断开电源 vs 不断开电源**：
- 断开电源：Q 不变，U 和 E 会变
- 不断开电源：U 不变（等于电源电压），Q 和 E 会变
⚠️ **电容器串联后总电容变小**（与电阻串联相反）
