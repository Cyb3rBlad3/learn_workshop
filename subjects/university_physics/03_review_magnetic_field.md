## 一、已学内容：磁感应强度与毕奥-萨伐尔定律

### 1.1 磁感应强度 B

磁场中某点的磁感应强度 **B** 描述了磁场的强弱和方向。

单位：特斯拉（T），1 T = 1 Wb/m² = 1 kg/(A·s²)

### 1.2 毕奥-萨伐尔定律 ⭐⭐⭐

**电流元 Idl 在空间某点 P 产生的磁感应强度**：

```
dB = (μ₀/4π) · (Idl × r̂) / r²
```

其中：
- μ₀ = 4π × 10⁻⁷ T·m/A（真空磁导率）
- Idl 为电流元（矢量，方向为电流方向）
- r̂ 为从电流元指向场点 P 的单位矢量
- r 为电流元到场点的距离

**方向判定**：右手螺旋定则（dl × r̂ 的方向）

### 1.3 载流长直导线的磁场 ⭐⭐⭐（已学完）

**无限长直导线**在距导线 d 处的磁场：

```
B = μ₀I/(2πd)
```

**方向**：右手定则——拇指指向电流方向，四指弯曲方向为 B 的方向（环绕导线的同心圆）。

**推导过程**（毕萨定律积分）：

取导线上微元 dl，到场点距离 r，dl 与 r 的夹角为 θ：

```
dB = (μ₀/4π) · (I dl sinθ) / r²
```

设场点到导线的垂直距离为 d，用几何关系将 dl、r、θ 统一用一个变量表示后积分：

令 l = -d cotα（α 为 r 与导线的夹角），则：
- r = d/sinα
- dl = d/(sin²α) dα

代入积分得：

```
B = (μ₀I/4πd) ∫₀^π sinα dα = (μ₀I/4πd) · 2 = μ₀I/(2πd)
```

**有限长直导线**（了解）：

```
B = (μ₀I/4πd)(cosθ₁ - cosθ₂)
```

θ₁ 和 θ₂ 分别是导线两端对场点的张角。

- 无限长导线：θ₁ = 0, θ₂ = π → B = μ₀I/(2πd)
- 半无限长导线（一端在场点正对面）：θ₁ = 0, θ₂ = π/2 → B = μ₀I/(4πd)

### 典型例题

**例题 1：两根平行导线的磁场**

> 两根无限长平行导线相距 2a，分别通过方向相反的电流 I。求两导线连线中点处的磁感应强度。

**解**：

中点到每根导线的距离 d = a。

导线 1 在中点产生的 B₁ = μ₀I/(2πa)，方向由右手定则确定。

导线 2 在中点产生的 B₂ = μ₀I/(2πa)，方向由右手定则确定。

因为电流方向相反，在中点处两个 B 方向**相同**（都向同一方向）。

```
B = B₁ + B₂ = 2 × μ₀I/(2πa) = μ₀I/(πa)
```

**例题 2：圆形载流线圈圆心处的磁场**（预习/即将学到）

> 半径为 R 的圆形线圈通过电流 I，求圆心处的 B。

**解**：线圈上每个电流元 dl 到圆心距离 r = R，且 dl ⊥ r̂，所以 sinθ = 1。

```
dB = (μ₀/4π) · (Idl)/(R²)
```

对整个圆周积分（∮dl = 2πR）：

```
B = (μ₀/4π) · I·2πR/R² = μ₀I/(2R)
```

方向：右手定则，四指沿电流方向弯曲，拇指指向即为 B 方向。

## 二、待学内容预览

### 2.1 磁通量与磁场的高斯定理

```
∮B·dA = 0     （磁力线是闭合曲线，没有"磁荷"）
```

与静电场高斯定理的对比：静电场通量 = q/ε₀ ≠ 0，磁场通量恒为 0。

### 2.2 安培环路定理 ⭐⭐⭐（下一个重点）

```
∮B·dl = μ₀ΣI内
```

类比高斯定理：高斯定理用来求**对称电场**，安培环路定理用来求**对称磁场**。

**典型应用**：
- 无限长载流直螺线管内部：B = μ₀nI（n 为单位长度匝数）
- 载流螺绕环（环形螺线管）

### 2.3 安培力 ⭐⭐⭐

```
dF = Idl × B   （载流导线在磁场中受的力）
```

两平行导线间的力：F/l = μ₀I₁I₂/(2πd)
- 同向电流相吸，反向电流相斥

### 2.4 洛伦兹力 ⭐⭐⭐

```
F = qv × B
```

- 大小：F = qvBsinθ
- 方向：右手定则（正电荷）或左手（负电荷）
- **洛伦兹力不做功**（F ⊥ v）

带电粒子在匀强磁场中做**匀速圆周运动**：
```
r = mv/(qB)    （回旋半径）
T = 2πm/(qB)   （周期，与速度无关！）
```

## 三、恒定磁场常见题型总览

| 题型 | 使用方法 | 常见模型 |
|------|---------|---------|
| 求磁场 B | 毕奥-萨伐尔定律（积分） | 直导线、圆形线圈 |
| 求磁场 B | 安培环路定理 | 螺线管、螺绕环 |
| 求安培力 | F = ∫Idl × B | 两平行导线、导线在匀强磁场中 |
| 求洛伦兹力/运动 | F = qv × B | 带电粒子圆周运动 |
| 求磁通量 | Φ = ∫B·dA | 任意面上的磁通量 |
