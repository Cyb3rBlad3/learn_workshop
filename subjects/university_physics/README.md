# 大学物理

## 基本信息
- **院校**：华南师范大学
- **专业**：计算机科学与技术（师范）
- **参考教材**：马文蔚《物理学》（第七版）上册，高等教育出版社
- **课程性质**：专业基础课

## 学习目标
掌握力学和电磁学的基本概念、定理和计算方法，达到工科计算机专业大学物理的基本要求。

## 专业适配说明
计算机科学与技术专业对大学物理的要求与纯物理/电子专业有所不同：
- **力学**：侧重动量、能量守恒的计算；角动量部分**了解即可，但需会算角动量**
- **电磁学**：侧重静电场、恒定磁场的计算；麦克斯韦方程组了解积分形式即可
- **热学/光学/近代物理**：视教学安排，通常为选讲或了解层次
