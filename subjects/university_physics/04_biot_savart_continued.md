## 概述

上节课学完了长直导线的磁场，本节继续毕奥-萨伐尔定律的另一个重要应用——**圆形载流线圈轴线上的磁场**。这是期末必考模型，也是理解磁矩、电磁感应的基础。

回忆一下毕奥-萨伐尔定律：

$$d\vec{B} = \frac{\mu_0}{4\pi} \cdot \frac{I \, d\vec{l} \times \hat{r}}{r^2}$$

上节课我们用它推导了无限长直导线的 B = μ₀I/(2πd)。现在换一个几何模型。

## 详细讲解

### 一、圆形载流线圈轴线上的磁场

#### 物理模型

一个半径为 R 的圆形线圈，通有电流 I。求轴线上距圆心 x 处的 P 点的磁感应强度。

```
        ← R →
      ___●___          轴线
     /   |   \         ↑
    |    |    |        |  x（P点到圆心的距离）
     \   |   /         |
      ‾‾‾●‾‾‾          P（场点）
```

#### 推导过程

**第一步：取电流元，写 dB**

在线圈上取一小段电流元 Idl。该电流元到场点 P 的距离为：

```
r = √(R² + x²)
```

由毕奥-萨伐尔定律：

```
dB = (μ₀/4π) · (Idl sinα) / r²
```

关键点：**圆形线圈上每个电流元 dl 都垂直于它到场点的连线在 dl 所在平面的投影**，即 dl ⊥ r̂，所以 sinα = 1（这是圆形线圈的特殊性质，和直导线不同！）

因此：
```
dB = (μ₀/4π) · Idl / r² = (μ₀/4π) · Idl / (R² + x²)
```

**第二步：分析对称性，确定方向**

每个 dB 的方向垂直于 dl 和 r 构成的平面。将 dB 分解为：
- **沿轴线方向的分量** dB∥：这些分量全部同向（都沿轴线方向），会累加
- **垂直轴线方向的分量** dB⊥：线圈上对称位置的两个电流元产生的 dB⊥ 方向相反，**完全抵消**

所以最终只剩轴线方向的分量：

```
dB∥ = dB · sinθ
```

其中 sinθ = R/r = R/√(R² + x²)

**第三步：积分**

```
B = ∮ dB∥ = ∮ (μ₀/4π) · Idl/(R² + x²) · R/√(R² + x²)
```

把常数提出来，∮dl = 2πR（圆周长）：

```
B = (μ₀/4π) · IR/(R² + x²)^(3/2) · 2πR
```

化简得到最终公式：

### ★ 圆形载流线圈轴线上的磁场公式

```
B = μ₀IR² / [2(R² + x²)^(3/2)]
```

方向：沿轴线，用**右手定则**——四指沿电流方向弯曲，拇指所指即为 B 方向。

#### 两个特殊位置

**① 圆心处（x = 0）**：

```
B₀ = μ₀I/(2R)
```

这个公式非常简洁，必须背住！

**② 远离线圈处（x >> R）**：

```
B ≈ μ₀IR²/(2x³) = μ₀m/(2πx³)
```

其中 m = IπR² 是**磁矩**。远处磁场与距离的三次方成反比。

### 二、磁矩

**定义**：载流线圈的磁矩

```
m = NIS
```

- N = 匝数
- I = 电流
- S = 线圈面积（不一定是圆形）

磁矩是矢量，方向由右手定则确定：四指沿电流方向，拇指为 m 的方向。

磁矩的意义：远处的磁场行为只取决于磁矩大小，而不取决于线圈的具体形状和大小（类比电偶极子）。

### 三、磁场叠加原理

多个载流导线产生的总磁场 = 各导线单独产生的磁场的**矢量和**。

```
B_总 = B₁ + B₂ + B₃ + ...    （矢量叠加）
```

这和电场叠加原理完全类似。

---

## 重要公式汇总

| 公式 | 适用场景 |
|------|---------|
| B = μ₀I/(2πd) | 无限长直导线，距离 d 处 |
| B = μ₀IR²/[2(R²+x²)^(3/2)] | 圆形线圈轴线上，距圆心 x |
| B = μ₀I/(2R) | 圆形线圈圆心处 |
| m = NIS | 磁矩定义 |

## 典型例题

### 例题 1：圆形线圈圆心处的磁场

**题目**：半径 R = 10cm 的圆形线圈共 100 匝，通过电流 I = 2A。求圆心处的磁感应强度。

**解题思路**：N 匝线圈相当于 N 个单匝线圈叠加，圆心处 B 直接乘以 N。

**详细解答**：

```
B = N · μ₀I/(2R)
  = 100 × (4π × 10⁻⁷ × 2) / (2 × 0.1)
  = 100 × 4π × 10⁻⁷ / 0.1
  = 100 × 4π × 10⁻⁶
  = 4π × 10⁻⁴
  ≈ 1.26 × 10⁻³ T
  = 1.26 mT
```

**答案**：B ≈ 1.26 × 10⁻³ T

---

### 例题 2：轴线上某点的磁场

**题目**：半径 R = 0.1m 的单匝圆形线圈，通过电流 I = 5A。求轴线上距圆心 x = 0.1m 处的磁感应强度。

**解题思路**：直接代入轴线公式。注意 x = R 时的计算。

**详细解答**：

```
B = μ₀IR² / [2(R² + x²)^(3/2)]
```

R = x = 0.1m，所以 R² + x² = 0.02

```
(R² + x²)^(3/2) = (0.02)^(3/2) = (0.02)^1 × (0.02)^(1/2)
                 = 0.02 × 0.1414
                 = 2.828 × 10⁻³
```

```
B = (4π × 10⁻⁷ × 5 × 0.01) / (2 × 2.828 × 10⁻³)
  = (4π × 5 × 10⁻⁹) / (5.656 × 10⁻³)
  = 20π × 10⁻⁹ / (5.656 × 10⁻³)
  = 62.83 × 10⁻⁹ / (5.656 × 10⁻³)
  = 1.11 × 10⁻⁵ T
  ≈ 11.1 μT
```

**答案**：B ≈ 1.11 × 10⁻⁵ T

对比圆心处 B₀ = μ₀I/(2R) = 4π×10⁻⁷×5/(2×0.1) = π×10⁻⁵ ≈ 3.14×10⁻⁵ T。

距圆心一个 R 的地方，B 已经降到圆心的约 1/3。

### 例题 3：磁场叠加——两个同轴线圈

**题目**：两个相同的圆形线圈（半径 R、电流 I、同方向），同轴放置，相距 d = R（亥姆霍兹线圈）。求两线圈正中间点的磁感应强度。

**解题思路**：中间点到两个线圈的距离相等，都是 x = R/2。两个线圈在中间点产生的 B 方向相同（电流同向），直接相加。

**详细解答**：

每个线圈在中间点产生的 B：

```
B₁ = μ₀IR² / [2(R² + (R/2)²)^(3/2)]
   = μ₀IR² / [2(R² + R²/4)^(3/2)]
   = μ₀IR² / [2(5R²/4)^(3/2)]
   = μ₀IR² / [2 · (5/4)^(3/2) · R³]
   = μ₀I / [2 · (5/4)^(3/2) · R]
```

计算 (5/4)^(3/2) = (5/4)^1 × (5/4)^(1/2) = 1.25 × 1.118 = 1.398

```
B₁ = μ₀I / (2 × 1.398 × R) = μ₀I / (2.796R)
```

两个线圈叠加：

```
B = 2B₁ = μ₀I / (1.398R) ≈ 0.716 μ₀I/R
```

也可以写成精确形式：**B = (4/5)^(3/2) · μ₀I/R ≈ 0.7155 μ₀I/R**

**答案**：B = (4/5)^(3/2) · μ₀I/R

**物理意义**：亥姆霍兹线圈的特点是中间区域磁场非常均匀，实验中常用来产生均匀磁场。

## 常见题型与解题方法

| 题型 | 方法 | 注意事项 |
|------|------|---------|
| 求圆形线圈圆心/轴线上的 B | 直接套公式 | N 匝要乘 N |
| 多个线圈/导线的叠加 | 分别求各自的 B，矢量相加 | 注意方向！同向加，反向减 |
| 直导线 + 圆弧组合（如半圆形导线） | 分段计算：直线段用直导线公式，圆弧用圆心公式的比例 | 直线段过圆心时对圆心不产生 B |
| 求磁矩 | m = NIS | S 是面积，不是周长 |

**特别提醒：半圆形导线在圆心处的磁场**

半圆 = 整圆的一半，所以 B = μ₀I/(4R)

四分之一圆 = 整圆的 1/4，所以 B = μ₀I/(8R)

推广：圆弧角度为 φ（弧度）的载流圆弧，在圆心处：

```
B = μ₀Iφ / (4πR)
```

## 易错点提醒

⚠️ **轴线公式只在轴线上成立**：B = μ₀IR²/[2(R²+x²)^(3/2)] 只适用于轴线上的点。轴线外的点没有简洁的解析表达式（需要椭圆积分），不会考。

⚠️ **N 匝线圈别忘乘 N**：B₀ = Nμ₀I/(2R)，很多同学忘了乘匝数。

⚠️ **叠加时注意方向**：两个线圈电流方向相同 → B 同向，相加；电流方向相反 → B 反向，相减。一定要先用右手定则判断每个 B 的方向。

⚠️ **直线段对其延长线上的点没有磁场贡献**：如果导线是一段直线 + 一段圆弧的组合形状，直线部分如果恰好通过圆弧的圆心，那么这段直线对圆心处的 B 贡献为零（因为 dl × r̂ = 0）。

---

## 小结

- 圆形线圈轴线磁场公式是毕奥-萨伐尔定律的第二个核心应用（第一个是直导线）
- **圆心处 B = μ₀NI/(2R)**，简洁易记
- 磁矩 m = NIS 描述线圈"产生磁场的能力"
- 组合导线问题的关键是"分段 + 叠加"

## 练习题

**1.** 半径 R = 5cm 的单匝圆形线圈通电流 I = 3A，求：
   - (a) 圆心处的 B
   - (b) 轴线上距圆心 10cm 处的 B

   答案：(a) B = 4π×10⁻⁷×3/(2×0.05) = 3.77×10⁻⁵ T；(b) 代入公式自行计算，约 3.38×10⁻⁶ T

**2.** 如图所示导线由两段半无限长直导线和一个半径为 R 的半圆弧组成（半圆弧的两端分别连接两段直线，直线通过圆心）。通过电流 I，求圆心 O 处的磁感应强度。

   提示：两段直导线在 O 点的 B 贡献为零（dl ∥ r̂），只有半圆弧有贡献。答案：B = μ₀I/(4R)，方向垂直纸面。

**3.** 两个共轴的圆形线圈，半径相同为 R，相距 2R，通过相同大小但方向相反的电流。求两线圈中点的磁感应强度。

   提示：两个 B 方向相反，在中点相减为零。答案：B = 0。
