## 概述

力学是大学物理的基础，包括质点运动学、牛顿定律、三大守恒定律、刚体转动四大板块。对计算机专业而言，重点掌握前三章的计算，第四章（刚体/角动量）了解概念、**会算角动量即可**。

## 一、质点运动学（第一章）

### 核心公式

| 物理量 | 定义/公式 | 说明 |
|--------|----------|------|
| 位矢 | **r** = x**i** + y**j** + z**k** | 描述位置 |
| 速度 | **v** = d**r**/dt | 位矢对时间的导数 |
| 加速度 | **a** = d**v**/dt = d²**r**/dt² | 速度对时间的导数 |
| 角速度 | ω = dθ/dt | 圆周运动 |
| 切向加速度 | aτ = dv/dt = Rα | 改变速度大小 |
| 法向加速度 | aₙ = v²/R = ω²R | 改变速度方向 |

### 常见题型

**题型 1：已知运动方程 r(t)，求 v(t) 和 a(t)**
- 方法：直接对 r(t) 求一阶导得 v，再求导得 a
- 例：x = 3t², y = 4t → vₓ = 6t, vᵧ = 4 → aₓ = 6, aᵧ = 0

**题型 2：已知 a(t) 和初始条件，求 v(t) 和 r(t)**
- 方法：积分 a(t) 得 v(t)，再积分得 r(t)，用初始条件定积分常数

**题型 3：圆周运动中线量与角量的换算**
- 核心关系：v = Rω，aτ = Rα，aₙ = v²/R

### 易错点
⚠️ **位移 ≠ 路程**：位移是矢量（首尾相连），路程是标量（轨迹总长度）
⚠️ **法向加速度方向**：始终指向曲率中心，即使速度不变也有 aₙ
⚠️ 角速度 ω 的单位是 rad/s，不要漏掉 rad

## 二、牛顿运动定律（第二章）

### 核心知识

- **牛顿第二定律**：ΣF = ma（矢量方程，需分解到各坐标轴）
- **隔离体法**：受力分析的标准方法——画隔离体图→标出所有力→列方程

### 常见题型

**题型 1：受力分析 + 列方程求加速度/力**
- 步骤：选对象 → 画受力图 → 选坐标系 → 沿各轴列 F = ma → 解联立方程

**题型 2：绳拉物体/斜面/连接体问题**
- 方法：分别对每个物体隔离分析，用内力互为作用力反作用力联立

**题型 3：变力问题（给出 F(t) 或 F(x)）**
- 方法：用微分方程 F = m(dv/dt) 积分求解

### 易错点
⚠️ **绳的张力不等于物体的重力**（加速运动时 T ≠ mg）
⚠️ **摩擦力方向**：与相对运动方向（或相对运动趋势方向）相反，不一定与运动方向相反
⚠️ **法向力/支持力**不一定等于 mg（斜面上、曲面运动时）

## 三、动量守恒与能量守恒（第三章）⭐⭐⭐ 重中之重

### 核心公式一览

| 定理/定律 | 公式 | 适用条件 |
|-----------|------|---------|
| 动量定理 | ∫F dt = Δ**p** = m**v₂** - m**v₁** | 任意情况 |
| 动量守恒 | Σ**p** = 常量 | 合外力为零 |
| 动能定理 | W合 = ΔEk = ½mv₂² - ½mv₁² | 任意情况 |
| 功能原理 | W非保守 = ΔE机械 | 任意情况 |
| 机械能守恒 | Ek₁ + Ep₁ = Ek₂ + Ep₂ | 只有保守力做功 |

### 碰撞问题（必考）

| 碰撞类型 | 动量守恒 | 动能守恒 | 特征 |
|----------|---------|---------|------|
| 完全弹性碰撞 | ✅ | ✅ | 两个方程联立求解 |
| 完全非弹性碰撞 | ✅ | ❌（损失最大） | 碰后粘在一起，v₁' = v₂' |
| 非完全弹性碰撞 | ✅ | ❌（部分损失） | 需额外条件（恢复系数） |

**完全弹性碰撞公式**（一维，m₂ 初始静止）：

```
v₁' = (m₁ - m₂)/(m₁ + m₂) · v₁
v₂' = 2m₁/(m₁ + m₂) · v₁
```

### 常见题型

**题型 1：碰撞问题**
- 列动量守恒 + 能量关系（弹性碰撞加动能守恒）

**题型 2：功与动能定理**
- 求变力做的功 W = ∫F·dx，再用动能定理联立

**题型 3：机械能守恒综合题**
- 判断是否只有保守力做功 → 列守恒方程

**题型 4：动量定理求冲量/平均力**
- 子弹嵌入木块、球撞墙等问题

### 典型例题

**例题：完全非弹性碰撞**
> 质量 m₁ = 2kg 的小球以 v₁ = 4m/s 撞上静止的 m₂ = 3kg 小球，碰后粘在一起。求碰后速度和动能损失。

**解**：
动量守恒：m₁v₁ = (m₁ + m₂)v'

v' = m₁v₁/(m₁ + m₂) = 2×4/(2+3) = **1.6 m/s**

动能损失：ΔEk = ½m₁v₁² - ½(m₁+m₂)v'²
= ½×2×16 - ½×5×2.56 = 16 - 6.4 = **9.6 J**

### 易错点
⚠️ **动量是矢量**：列守恒方程时必须注意正方向，反向的速度取负号
⚠️ **功能原理 vs 动能定理**：功能原理中的 W 只包含非保守力的功；动能定理中的 W 是所有力的功
⚠️ **弹性势能不要忘**：弹簧问题中势能 Ep = ½kx²

## 四、刚体转动与角动量（第四章）⭐ 了解为主，会算角动量

### 必须会算的：角动量

**质点的角动量**（对某参考点 O）：

```
L = r × p = r × mv
```

大小：L = rmv sinθ（r 为位矢，θ 为 r 与 v 的夹角）

**特殊情况**：
- 质点做圆周运动：L = mvr = mr²ω
- 刚体定轴转动：L = Jω（J 为转动惯量）

### 常见转动惯量（了解即可）

| 刚体 | 转轴 | 转动惯量 J |
|------|------|-----------|
| 细环（质量 M、半径 R） | 过中心垂直环面 | MR² |
| 均匀圆盘 | 过中心垂直盘面 | ½MR² |
| 均匀细棒 | 过中心垂直棒 | ML²/12 |
| 均匀细棒 | 过端点垂直棒 | ML²/3 |

### 角动量守恒定律（了解条件和结论）

当合外力矩 M = 0 时：**L = Jω = 常量**

经典例子：花样滑冰运动员收紧手臂 → J 减小 → ω 增大

### 典型例题：计算角动量

**例题**：质量 m = 0.5kg 的质点在半径 R = 2m 的圆周上以 v = 3m/s 匀速运动，求其对圆心的角动量。

**解**：圆周运动中 v ⊥ r，所以 sinθ = 1

L = mvR = 0.5 × 3 × 2 = **3 kg·m²/s**

方向：由右手定则确定，垂直于圆面。

### 易错点
⚠️ **角动量的参考点很重要**：同一质点对不同参考点的角动量不同
⚠️ **L = mvr sinθ 中的 θ**：是 **r** 与 **v** 之间的夹角，不是与其他方向的夹角
