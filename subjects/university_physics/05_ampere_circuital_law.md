# 安培环路定理与磁场的高斯定理

> 学习日期: 2026-05-12
> 所属科目: 大学物理
> 难度要求: ⭐⭐⭐掌握

## 概述

毕奥-萨伐尔定律可以求任意形状电流的磁场，但计算量大。**安培环路定理**是求磁场的第二件"武器"——对于具有高对称性的电流分布，安培环路定理可以快速求解。

它的地位完全类比静电场中的**高斯定理**：
- 高斯定理：利用对称性求 **E**（面积分 → 体内电荷）
- 安培环路定理：利用对称性求 **B**（线积分 → 穿过的电流）

本节还包含磁通量和磁场的高斯定理（∮B·dA = 0），这是理解电磁感应的前置知识。

---

## 核心知识点

- 磁通量的定义 Φ = ∫B·dA ⭐⭐⭐
- 磁场的高斯定理 ∮B·dA = 0 ⭐⭐⭐
- 安培环路定理 ∮B·dl = μ₀ΣI ⭐⭐⭐
- 用安培环路定理求磁场的条件和步骤 ⭐⭐⭐
- 三种经典模型：螺线管、螺绕环、同轴电缆 ⭐⭐⭐

---

## 详细讲解

### 一、磁通量与磁场的高斯定理

#### 磁通量

定义和电通量完全类比：

```
Φ_B = ∫∫ B · dA = ∫∫ B cosθ dA
```

单位：韦伯（Wb），1 Wb = 1 T·m²

#### 磁场的高斯定理

```
∮ B · dA = 0
```

**物理意义**：穿过任何闭合曲面的磁通量恒为零。

**直白理解**：磁力线是闭合曲线（没有起点也没有终点），从闭合面穿出去的磁力线一定会从另一处穿回来，所以进出相抵为零。这也意味着**不存在磁单极子**（没有"磁荷"）。

**与静电场高斯定理的对比**：

| | 静电场 | 磁场 |
|---|---|---|
| 高斯定理 | ∮E·dA = Σq/ε₀ | ∮B·dA = 0 |
| 右边 | 可以不为零 | 恒为零 |
| 原因 | 存在电荷（电力线有起止点） | 不存在磁荷（磁力线闭合） |

> 🔗 **为什么要学这个？** 磁通量 Φ 是电磁感应的核心概念——法拉第定律 ε = -dΦ/dt 就是磁通量的变化率。所以这里把磁通量搞清楚，后面学电磁感应就顺了。

---

### 二、安培环路定理

#### 定理表述

```
∮ B · dl = μ₀ · ΣI_内
```

**文字表述**：磁感应强度沿任意闭合路径的线积分（环流），等于被该闭合路径所穿过的全部电流的代数和乘以 μ₀。

#### 电流正负的判定

采用**右手螺旋关系**：
- 右手四指沿环路积分方向弯曲
- 拇指所指方向为正方向
- 与拇指同向的电流为正，反向为负

#### 重要说明

1. ∮B·dl 中的 B 是**所有电流**（包括环路内外的）共同产生的总磁场
2. 但右边 ΣI 只算**穿过环路围成的面**的电流
3. 环路外的电流虽然对 B 有贡献，但它们的贡献在一圈积分下来恰好为零

这和高斯定理是一样的道理：面外的电荷虽然影响 E 的分布，但不影响总通量。

---

### 三、用安培环路定理求磁场

#### 使用条件

电流分布必须有**足够的对称性**，使得在所选的安培环路上，B 要么是常数，要么为零，要么与路径垂直（B·dl = 0）。

#### 解题四步法

**① 分析对称性**：判断 B 的方向和大小的分布规律

**② 选环路**：选择一条闭合路径，使得：
- B 在路径上大小为常数（可提到积分号外）
- 或 B 与路径垂直（点积为零，不贡献）

**③ 算左边**：∮B·dl = B × L（L 为有效积分路径长度）

**④ 算右边**：μ₀ × 穿过环路的电流代数和，解出 B

---

### 四、三种经典模型

#### 模型 1：无限长载流直螺线管 ⭐⭐⭐（必考）

**结论**：
```
管内：B = μ₀nI    （均匀磁场，n = 匝数/长度 = N/L）
管外：B = 0
```

**推导**：

选取矩形安培环路 abcd：
- ab 边在管内，平行于轴线（长度 l）
- cd 边在管外，平行于轴线
- bc 和 da 垂直于轴线

```
       管外（B=0）
  d ←————————————— c
  |                |
  |  螺线管内部    |  ← 这里 B 沿轴线方向
  |                |
  a ——————————————→ b
       管内（B≠0）
```

∮B·dl = B·l（ab边） + 0（bc边，B⊥dl） + 0（cd边，B=0） + 0（da边，B⊥dl）

= B·l

穿过环路的电流：环路内有 nl 匝，每匝电流 I，所以 ΣI = nlI

由安培环路定理：

```
Bl = μ₀nlI
B = μ₀nI
```

#### 模型 2：载流螺绕环（环形螺线管） ⭐⭐

**结论**：
```
环内：B = μ₀NI/(2πr)    （N = 总匝数，r = 环路半径）
环外：B = 0
```

选取以环中心为圆心的同心圆作为安培环路。

环内（R₁ < r < R₂）：∮B·dl = B·2πr = μ₀NI → B = μ₀NI/(2πr)

如果螺绕环截面很小（R₂ - R₁ << R平均），可近似：B ≈ μ₀nI（n = N/(2πR)）

#### 模型 3：同轴电缆（无限长载流圆柱导体） ⭐⭐⭐

半径为 R 的无限长圆柱导体，均匀载流 I。

选取同心圆安培环路（半径 r）：

**r > R（导体外部）**：
```
B · 2πr = μ₀I
B = μ₀I/(2πr)    ← 和无限长直导线一样！
```

**r < R（导体内部，电流均匀分布）**：

穿过的电流只有 r 以内的部分：I_内 = I · (πr²)/(πR²) = Ir²/R²

```
B · 2πr = μ₀ · Ir²/R²
B = μ₀Ir/(2πR²)    ← B 与 r 成正比！
```

**总结**：
```
r < R:  B = μ₀Ir/(2πR²)   （线性增长）
r = R:  B = μ₀I/(2πR)     （最大值）
r > R:  B = μ₀I/(2πr)     （反比下降）
```

这个 B(r) 分布图的形状和均匀带电球体的 E(r) 非常类似！

## 重要公式汇总

| 公式 | 适用模型 |
|------|---------|
| ∮B·dA = 0 | 磁场高斯定理（普遍成立） |
| ∮B·dl = μ₀ΣI | 安培环路定理（普遍成立） |
| B = μ₀nI | 无限长密绕螺线管内部 |
| B = μ₀NI/(2πr) | 螺绕环内部 |
| B = μ₀I/(2πr) | 无限长直导线/圆柱导体外部 |
| B = μ₀Ir/(2πR²) | 均匀载流圆柱导体内部 |

## 典型例题

### 例题 1：螺线管内的磁场

**题目**：一个长 L = 0.5m 的密绕螺线管，共 1000 匝，通过电流 I = 2A。求管内的磁感应强度。

**解题思路**：直接用 B = μ₀nI，先算 n。

**详细解答**：

```
n = N/L = 1000/0.5 = 2000 匝/m

B = μ₀nI = 4π × 10⁻⁷ × 2000 × 2
  = 16π × 10⁻⁴
  ≈ 5.03 × 10⁻³ T
  ≈ 5.03 mT
```

**答案**：B ≈ 5.03 × 10⁻³ T

---

### 例题 2：同轴电缆的磁场分布

**题目**：一根半径 R = 1cm 的长直圆柱导体，均匀通过电流 I = 10A。求：
- (a) 距轴线 r₁ = 0.5cm 处（导体内部）的 B
- (b) 距轴线 r₂ = 3cm 处（导体外部）的 B

**详细解答**：

(a) r₁ = 0.5cm < R = 1cm，在导体内部：
```
B = μ₀Ir₁/(2πR²)
  = (4π × 10⁻⁷ × 10 × 0.005) / (2π × 0.01²)
  = (4π × 5 × 10⁻⁹) / (2π × 10⁻⁴)
  = (20π × 10⁻⁹) / (2π × 10⁻⁴)
  = 10 × 10⁻⁵
  = 1.0 × 10⁻⁴ T = 0.1 mT
```

(b) r₂ = 3cm > R = 1cm，在导体外部：
```
B = μ₀I/(2πr₂)
  = (4π × 10⁻⁷ × 10) / (2π × 0.03)
  = (40π × 10⁻⁷) / (6π × 10⁻²)
  = (40/6) × 10⁻⁵
  = 6.67 × 10⁻⁵ T ≈ 0.067 mT
```

**答案**：(a) B = 1.0 × 10⁻⁴ T；(b) B ≈ 6.67 × 10⁻⁵ T

---

### 例题 3：安培环路定理判断题

**题目**：如图，一无限长直导线通过电流 I₁，一个圆形环路 C 包围该导线。在环路旁边还有一根平行导线通过电流 I₂。∮B·dl = ?

**解题思路**：安培环路定理右边只算穿过环路的电流。I₂ 在环路外面，不算。

**答案**：∮B·dl = μ₀I₁

注意：虽然 I₂ 也会影响环路上各点的 B 值（使得 B 不再处处相等），但 I₂ 对整个环路积分的贡献恰好为零。**所以 ∮B·dl 的值只由穿过环路的电流决定。**

## 常见题型与解题方法

| 题型 | 方法 | 关键点 |
|------|------|--------|
| 求螺线管/螺绕环内的 B | 安培环路定理 + 矩形/圆形环路 | 确定 n 或 N |
| 求圆柱导体内外的 B | 安培环路定理 + 同心圆环路 | 内部电流按面积比算 |
| 判断 ∮B·dl 的值 | 只算穿过环路的电流 | 外部电流不计入 |
| 求磁通量 | Φ = ∫B·dA | 注意 B 可能不均匀，需要积分 |

## 安培环路定理 vs 高斯定理 对比（帮助记忆）

| 对比项 | 高斯定理（电场） | 安培环路定理（磁场） |
|--------|----------------|-------------------|
| 数学形式 | ∮E·dA = Σq/ε₀ | ∮B·dl = μ₀ΣI |
| 积分类型 | 面积分（闭合曲面） | 线积分（闭合路径） |
| 选取的"面/路" | 高斯面 | 安培环路 |
| 右边的"源" | 包围的电荷 | 穿过的电流 |
| 选面/路的原则 | E 在面上为常数 | B 在路径上为常数 |
| 经典对称性 | 球/柱/面 | 柱/螺线管/螺绕环 |

**记忆口诀**：高斯管面（积分）算电荷，安培环路（积分）算电流。

---

## 易错点提醒

⚠️ **B 在环路上不一定是常数**：安培环路定理 ∮B·dl = μ₀ΣI 是**普遍成立**的，但只有当 B 在环路上为常数时才能简化为 B·L = μ₀ΣI。选环路的目的就是让 B 变成常数。

⚠️ **螺线管公式 B = μ₀nI 中的 n**：n 是**单位长度**的匝数（匝/m），不是总匝数 N。n = N/L。

⚠️ **导体内部 B 的电流计算**：均匀分布时，r 以内的电流 I_内 = I·(r²/R²)，是按**面积比**算的，不是按半径比。

⚠️ **安培环路定理右边电流的正负**：一定要用右手定则！如果有多个电流穿过环路，方向不同的要带上正负号。

---

## 小结

- **磁场的高斯定理** ∮B·dA = 0 告诉我们磁力线是闭合的（没有磁荷）
- **安培环路定理** ∮B·dl = μ₀ΣI 是求对称磁场的高效工具
- 三个必会模型：螺线管（B = μ₀nI）、螺绕环、载流圆柱导体
- 与静电场的高斯定理形成完美对比，掌握类比关系有助于记忆

## 练习题

**1.** 一个密绕螺线管每厘米绕 20 匝，通过电流 0.5A。求管内磁感应强度。
   答案：n = 2000匝/m，B = μ₀nI = 4π×10⁻⁷×2000×0.5 ≈ 1.26×10⁻³ T

**2.** 一根半径 R = 2cm 的无限长圆柱导体，均匀通过电流 I = 20A。画出 B 随 r 变化的图像，并标出 r = R 处的 B 值。
   答案：r = R 处 B = μ₀I/(2πR) = 4π×10⁻⁷×20/(2π×0.02) = 2×10⁻⁴ T

**3.** 同轴电缆由内导体（半径 a，电流 I 向右）和外导体（内径 b，外径 c，电流 I 向左）组成。分别求以下区域的 B：(a) r < a；(b) a < r < b；(c) b < r < c；(d) r > c。
   提示：(d) r > c 时，穿过环路的总电流 = I + (-I) = 0，所以 B = 0。这就是同轴电缆不对外产生磁场干扰的原理！
