## 学习目标

1. 熟练判定一阶方程 $P\,\mathrm{d}x+Q\,\mathrm{d}y=0$ 是否为全微分方程，并会用偏积分法或折线法求势函数 $u(x,y)$。
2. 理解积分因子的几何与分析意义，掌握仅与 $x$ 或仅与 $y$ 有关的积分因子判别式与指数型公式。
3. 能对常见题型（含简单变量替换后求 $\mu$）完成通解书写，并识别易错符号与定义域问题。
