# learn_workshop

My learning notes and diaries.

## 仓库结构

```
├── AGENTS.md          # Cursor Agent 规则
├── README.md          # 本文件
├── progress.md        # 学习进度总表
└── subjects/          # 学习科目目录
    └── {科目名}/
        ├── README.md  # 科目概述与学习目标
        └── NN_xxx.md  # 结构化教学章节
```

## 使用方式

与 Cursor Agent 对话即可开始学习。Agent 会自动：
- 创建科目文件夹和教学文件
- 记录学习进度到 `progress.md`
- 在对应科目文件夹中写入结构化的教学内容

详细规则见 [AGENTS.md](./AGENTS.md)。
